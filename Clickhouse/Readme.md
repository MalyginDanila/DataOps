# Настройка ClickHouse с помощью Docker Compose

1. Запустите ClickHouse с помощью docker-compose. При запуске должна автоматически создаваться учётная запись администратора, имеющая права на управление пользователями и ролями. Для задания прав этой учётной записи используйте файл users.xml.

2. После запуска сервера создайте две роли с помощью SQL-запросов:

   - Первая роль должна называться ddl_reader. Она должна предоставлять права на создание таблиц (CREATE TABLE) и чтение данных (SELECT).
   - Вторая роль должна называться writer_dropper. Она должна предоставлять права на удаление таблиц (DROP TABLE) и добавление данных в таблицы (INSERT).

3. Создайте двух пользователей с помощью SQL-запросов:

   - Пользователь user_reader должен получить роль ddl_reader.
   - Пользователь user_dropper должен получить роль writer_dropper.

4. Создайте таблицу movie_ratings со следующими столбцами:

   - movie_id типа UInt32
   - genre типа String
   - rating типа Float32

5. Затем создайте агрегирующую таблицу genre_avg_rating, использующую движок AggregatingMergeTree. Эта таблица должна хранить промежуточные состояния агрегатной функции для вычисления среднего значения rating по жанрам.

6. После этого создайте материализованное представление, которое будет автоматически обновлять данные в таблице genre_avg_rating при каждой вставке в movie_ratings.
