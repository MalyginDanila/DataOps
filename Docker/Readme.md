Приложение №1 представляет из себя Python скрипт, который читает системные логи из файла /var/log/syslog и выводит строки с ошибками в файл /shared/errors.log

Приложение №2 также написано на Python, но его задача вывести список обнаруженных ошибок в веб на порт 5000.

Необходимо: Написать dockerfile для каждого приложения и docker-compose, объединяющий два приложения
