В директории /var/logs/myapp/ хранятся лог-файлы веб-приложения. Каждый файл содержит строки в следующем формате:

INFO: Приложение запущено
INFO: Пользователь вошел в систему
WARNING: Использование памяти превышает 80%
INFO: Запрос к базе данных выполнен
ERROR: Не удалось подключиться к базе данных
WARNING: Диск почти заполнен
INFO: Завершение работы приложения
